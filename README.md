# escontroller

**escontroller** — модульная архитектурная библиотека для Unity Engine, предназначенная для создания расширяемых контроллеров игровых персонажей.

## О проекте

Библиотека решает проблему повторяющегося переписывания логики контроллеров персонажей для различных проектов. **escontroller** предоставляет гибкую модульную архитектуру, позволяющую быстро собирать контроллеры из переиспользуемых компонентов и расширять их под конкретные требования проекта.

### Основные преимущества

- **Модульность:** функциональность разделена на независимые подключаемые компоненты.
- **Переиспользуемость:** общие механизмы доступны через CoreModules для использования в разных игровых системах.
- **Расширяемость:** API разработано для создания собственных модулей без изменения ядра библиотеки.
- **Архитектурная чёткость:** явное разделение на ядро, общие модули и игровую логику.

## Архитектура

Библиотека организована в три уровня:

### Core

Фундаментальные типы и механизмы библиотеки:

- `CoreController` — центральный компонент, управляющий жизненным циклом подключённых модулей
- `ICoreModule` и `CoreModule` — контракт и базовый класс подключаемых модулей
- `ActionId` — типизированный идентификатор действия
- `MovementActions` — каталог встроенных идентификаторов действий перемещения

### CoreModules

Общие подключаемые компоненты, предоставляющие функциональность для различных игровых систем:

- `CheckGround` — модуль физической проверки контакта с поверхностью
- `ActionsController` — реестр зарегистрированных игровых действий
- `ActionsPermissionsController` — управление блокировками и разрешениями на выполнение действий

### GameModules

Компоненты, реализующие конкретные игровые системы и поведение объектов. Этот уровень находится в активной разработке и документируется по мере реализации.

## Быстрый старт

### Требования

- Unity 6 или выше
- Поддержка C# 8.0+

### Основы использования
На данный момент исходный код предоставлен в формате Unity проекта, поэтому не может использоваться как инструмент в формате Unity Packages. Версия, готовая к работе и установке будет предоставлена в релизе ALPHA1

Подробные примеры и описание API каждого компонента см. в [Library API](Library%20API.md).

## Статус проекта

**Текущая версия:** Pre-alpha (в активной разработке)

Проект находится на стадии формирования публичного API и стабилизации ядра. Библиотека не имеет стабильной версии, поэтому публичный контракт может изменяться между коммитами.

### Что уже реализовано

- ✅ Ядро управления модулями (Core)
- ✅ Система регистрации и разрешения действий (ActionsController, ActionsPermissionsController)
- ✅ Модуль проверки контакта с поверхностью (CheckGround)
- ✅ Типизированные идентификаторы действий (ActionId)
- ✅ Подробная документация API

### Планы развития

#### Краткосрочные (текущая разработка)

1. **Стабилизация Core API** — завершение тестирования жизненного цикла модулей и обработки ошибок
2. **Игровые модули движения** — реализация MovementController и базовых подмодулей перемещения
3. **Модульное тестирование** — покрытие тестами Core и CoreModules

#### Среднесрочные

4. **Система анимации** — интеграция с Animator и подключение к Action System
5. **Документация игровых модулей** — расширение Library API описанием GameModules
6. **Примеры проектов** — демонстрационные сцены с использованием библиотеки

#### Долгосрочные

7. **Первая стабильная версия (Alpha)** — публикация первой версии с гарантированным API
8. **Интеграция с Unity Input System** — поддержка новой системы ввода Unity
9. **Поддержка сообщества** — создание экосистемы дополнительных модулей
