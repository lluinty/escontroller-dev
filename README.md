# escontroller

**Модульный контроллер персонажа для Unity**

`escontroller` — экспериментальная библиотека для построения расширяемого контроллера персонажа. Ядро предоставляет общие данные и API, а подключаемые компоненты реализуют отдельные системы и используют ядро через контракт `ICoreModule`.

Проект находится в активной разработке: публичный API и архитектура могут меняться.

## Текущая архитектура

### CoreController

`CoreController` — центральный компонент ядра. Он:

- предоставляет ссылку на `Rigidbody` через `CoreRigidbody`;
- хранит список подключённых модулей и управляет их проверкой и инициализацией;
- предоставляет систему блокировок действий;
- хранит реестр действий, зарегистрированных модулями или другими системами.

### Core modules

Модуль ядра — компонент `MonoBehaviour`, реализующий интерфейс `ICoreModule`:

```csharp
public interface ICoreModule
{
    void Initialize(CoreController core);
}
```

При инициализации модуль получает ссылку на `CoreController`. При удалении из набора модулей ядро вызывает `Initialize(null)`, чтобы сообщить об отключении модуля.

Сейчас в проекте есть модуль `CheckGround`, который определяет нахождение персонажа на земле и предоставляет свойство `IsGrounded`.

### Action API

Для действий используется типизированный идентификатор `ActionId`. Ядро предоставляет два независимых механизма:

- **Action Permission** — несколько систем могут независимо блокировать одно действие. Действие доступно, пока у него нет активных блокировок.
- **Action Registry** — несколько авторов могут зарегистрировать одно действие. Оно остаётся в реестре, пока его не удалит последний автор.

Встроенный набор идентификаторов перемещения находится в `MovementActions`: `Move`, `Run`, `Jump`.

## Требования

- Unity **6000.6.7f1** (версия редактора, указанная в проекте).
- Unity Input System и Universal Render Pipeline присутствуют среди зависимостей проекта.

Проект экспериментальный. Перед использованием в стороннем проекте учитывайте, что API может измениться, а некоторые части архитектуры ещё находятся в разработке.
