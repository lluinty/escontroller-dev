# escontroller

**Modular Character Controller for Unity**

`escontroller` — экспериментальный проект модульного контроллера персонажа для Unity.

## О проекте

Основная цель проекта — разработать расширяемую архитектуру контроллера, в которой ядро предоставляет общий API, а отдельные модули реализуют конкретную функциональность персонажа.

Архитектура строится вокруг разделения ответственности: Core предоставляет общие интерфейсы и данные, а Modules используют их для реализации поведения.

## Основные компоненты

- **CoreController** — ядро персонажа. Предоставляет доступ к Rigidbody, определяет нахождение на земле и управляет действиями.
    
- **Action Contracts** — единый каталог идентификаторов действий.
    
- **Modules** — отдельные компоненты функциональности персонажа, взаимодействующие с Core через публичный API.

## Архитектурные принципы

- Минимальная связанность компонентов.
    
- Разделение ответственности между ядром и модулями.
    
- Единый публичный API для взаимодействия компонентов.
    
- Возможность расширения функциональности без необходимости изменять ядро.
    
- Независимое управление разрешениями действий.
