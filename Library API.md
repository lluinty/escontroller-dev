# API Reference
## Core
### `CoreController`

---
#### `Action Blocker`

`CanMove`, `CanRun`, `CanJump` — свойства типа `bool`, определяющие, разрешено ли игроку выполнять соответствующее действие.

Используются для ограничения действий игрока различными подмодулями.

**Важно:** установка свойства в `false` запрещает запуск или продолжение соответствующей логики только в тех местах, где предусмотрена проверка этого свойства. Она не гарантирует автоматического прекращения уже выполняемого действия.

Изменение доступности действий осуществляется через метод:

`SetCanPerform(PlayerAction action, string blockerId, bool canPerform)`

- `action` — действие, доступность которого необходимо изменить.
    
- `blockerId` — уникальный идентификатор блокировки.
    
- `canPerform` — разрешить (`true`) или запретить (`false`) действие.

Несколько блокировок одного действия могут существовать одновременно. Действие считается доступным только при отсутствии активных блокировок.

---
#### `Ground Checker`
`IsGrounded` - свойство типа `bool`, определяющее, стоит ли игрок на земле.

---
#### `Core Rigidbody`

`CoreRigidbody` - свойство возвращяющее ссылку на `Rigidbody` персонажа.

Используется для управления физикой персонажа из модулей.
